✅ STEP 1: INSTALL .NET 8.0 SDK
========================================================================

1. Download from: https://dotnet.microsoft.com/download/dotnet/8.0
2. Install and verify:
   
   Command Prompt:
   > dotnet --version
   
   Expected output: 8.0.x or higher

========================================================================
✅ STEP 2: CONFIGURE MONGODB CONNECTION
========================================================================

1. Get MongoDB Connection String from MongoDB Atlas:
   - Go to: https://www.mongodb.com/cloud/atlas
   - Create/Login to your cluster
   - Click "Connect" button
   - Get connection string for your application
   
   Format: mongodb+srv://<username>:<password>@<cluster>.mongodb.net/?appName=<appName>

2. Open: appsettings.json
   
   Find this section:
   ```
   "ConnectionStrings": {
     "MongoDB": "mongodb+srv://trinhhuyhoang255_db_user:<password>@websocket.zbsdb9k.mongodb.net/?appName=Websocket"
   }
   ```
   
   Replace <password> with your actual MongoDB password

3. Make sure IP address is whitelisted in MongoDB Atlas:
   - Security → Network Access
   - Add IP Address → Allow from Anywhere (for dev)

Open Command Prompt / PowerShell and run:

========================================================================
🆘 TROUBLESHOOTING
========================================================================

❌ ERROR: "No .NET SDKs found"
→ Install .NET 8.0 SDK from https://dotnet.microsoft.com/download

❌ ERROR: "MongoDB connection refused"
→ Check MongoDB Atlas:
  1. Verify connection string password
  2. Check IP is whitelisted (Network Access)
  3. Ensure cluster is running (not paused)

❌ ERROR: "Backend running but frontend won't connect"
→ Open browser DevTools (F12):
  1. Go to Console tab
  2. Look for WebSocket error
  3. Check CORS configuration in Program.cs
  4. Verify URL is http://localhost:5000 (not https)

❌ ERROR: "Connected but no messages appear"
→ Check:
  1. JavaScript errors in Console (F12)
  2. Network tab → WebSocket is connected
  3. Verify you're sending non-empty messages
  4. Check MongoDB for documents

❌ ERROR: "dotnet restore fails"
→ Run:
  dotnet nuget locals all --clear
  dotnet restore

📝 IMPORTANT NOTES
========================================================================

1. PORT: Backend runs on http://localhost:5000
   - If you need different port, edit launchSettings.json

2. DATABASE NAME: "RealtimeChatDB"
   - Collection: "messages"
   - Auto-created on first message

3. DEFAULT ROOM: "default-room"
   - All users join same room
   - Can be modified in wwwroot/index.html (const roomId)

4. MESSAGE HISTORY: Shows last 50 messages
   - Change in Services/ChatService.cs (limit = 50)

5. CORS: Allows connections from:
   - http://localhost:5173 (Vite)
   - http://localhost:3000 (React/Vue)
   - Add more origins in Program.cs if needed
